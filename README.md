# نيفو للتدريب – NIVO Academy

منصة كورسات أونلاين (مسجلة + لايف) بهوية نيفو (كحلي + ذهبي)، بمحفظة إلكترونية لكل مستخدم (شحن بإيصال تحويل + مراجعة إدارية).

**التقنية:** Next.js 15 (App Router) · TypeScript · Tailwind CSS · Prisma · SQLite (قابلة للتحويل إلى PostgreSQL) · Docker + Caddy.

## المميزات
- **الموقع العام:** رئيسية، كتالوج كورسات بفلاتر وبحث، صفحة كورس (منهج، معاينة مجانية، مدرب)، جدول اللايف، SEO + Sitemap + PWA.
- **الطالب:** تسجيل/دخول، لوحة تحكم، كورساتي مع نسبة التقدم، مشغّل دروس (YouTube / Vimeo / Bunny / mp4)، شهادة إتمام بكود تحقق (طباعة/PDF)، محفظة.
- **المحفظة:** طلب شحن (مبلغ + طريقة + رفع إيصال) ← مراجعة الأدمن (قبول/رفض) ← إضافة الرصيد في سجل معاملات لا يتعدّل ← شراء كورس بخصم ذري من الرصيد.
  - منع تكرار نفس الإيصال (SHA-256)، منع القبول المزدوج، الإيصالات خاصة (لا يراها إلا صاحبها والأدمن).
- **الأدمن (`/admin`):** نظرة عامة، طلبات الشحن، الكورسات والدروس، التصنيفات، اللايف، المستخدمون (تعديل رصيد/استرداد/إيقاف/ترقية)، الإعدادات (أرقام التحويل والتواصل).
- **اللايف:** تُضاف الجلسة برابط Zoom / Meet / Jitsi (سيرفر الـ VPS) ويظهر الرابط للمشتركين فقط.

## التشغيل محليًا (ويندوز / أي نظام)
```bash
npm install
cp .env.example .env        # عدّل AUTH_SECRET وبيانات الأدمن
npm run db:push             # إنشاء قاعدة البيانات
npm run db:seed             # تصنيفات + كورسات تجريبية + حساب الأدمن
npm run dev                 # http://localhost:3000
```
حسابات التجربة (بيئة التطوير فقط): الأدمن من `.env` (افتراضي `admin@nivo.local`) · طالب تجريبي `demo@nivo.local / Demo12345!` (رصيد 1000).

## النشر على الـ VPS
1. ثبّت Docker، وانسخ المشروع على السيرفر.
2. أنشئ `.env` بجانب `docker-compose.yml`:
   ```env
   SITE_DOMAIN=academy.example.com
   NEXT_PUBLIC_SITE_URL=https://academy.example.com
   AUTH_SECRET=<نص عشوائي طويل: openssl rand -base64 48>
   ADMIN_EMAIL=you@example.com
   ADMIN_PASSWORD=<كلمة مرور قوية>
   ```
3. وجّه الدومين (A record) إلى IP السيرفر، ثم: `docker compose up -d --build`
4. ادخل `/admin` وعدّل **الإعدادات** (أرقام التحويل الحقيقية) وأضف كورساتك. (في الإنتاج لا تُضاف كورسات تجريبية؛ للإضافة اضبط `SEED_SAMPLES=1`.)

**النسخ الاحتياطي:** احفظ دوريًا الـ volumes `nivo_data` (قاعدة البيانات) و`nivo_storage` (الإيصالات).

### التحويل إلى PostgreSQL (اختياري للتوسع)
في `prisma/schema.prisma` غيّر `provider = "sqlite"` إلى `"postgresql"`، واضبط `DATABASE_URL` ثم `npm run db:push`.

## الفيديو واللايف
- **مسجل:** الأفضل Bunny Stream (رخيص ومحمي) – انسخ رابط الـ embed في حقل "رابط الفيديو". يوتيوب (غير مدرج) وVimeo وmp4 مدعومة أيضًا.
- **لايف:** استخدم سيرفر اللايف الموجود على الـ VPS (Jitsi/BBB…) أو Zoom/Meet، وضع الرابط في جلسة اللايف.
